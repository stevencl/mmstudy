# Task Cards — Multi-Chat Mental Model Study

> Print one card per page, or reveal them one at a time on screen. Cards show
> **only what the participant should see** — no perturbation details, no system
> terminology. Moderator mechanics live in `06-moderator-guidance.md`.

### Task 0 — Getting started

Imagine you have **several AI assistants** helping you work on this project.

**How would you organise the work between them?**

Think out loud about:
- What separate things would you set up?
- What does each one do?
- What should each one know?
- What, if anything, is shared between them?

### Task 1 — Add tests

This app currently has **no tests**.

Add tests for the **frontend**, the **backend**, and the **shared** logic.

Please use **more than one** AI assistant, and divide the work however makes
sense to you.

### Task 2 — Tagging and filtering

Noteshelf has no tags yet. Add **tags** to notes, and the ability to **filter**
notes by tag.

Do it in two parts:

1. **First, the interface.** Using the **Frontend** assistant, let people add
   tags when creating a note, see a note's tags, and filter the list by tag.
2. **Then the server side.** Using the **Backend** assistant, make the server
   store tags and filter against them.

I'm the product owner — **ask me to clarify** requirements whenever you need to.

## ✂ — — — — — — — — — — — — — — — — — — — — — — — — — — — — — —

### Task 2b — An alternative version

You built multi-tag filtering **one way** — matching **ALL** the selected tags,
or **ANY** of them (whichever you chose).

I'd like to see the **opposite** version too — the one you *didn't* build.

Starting from where you are right now, find a way to try this alternative
**without losing the version you've already got**. Build it, then help me
**compare the two**.

## ✂ — — — — — — — — — — — — — — — — — — — — — — — — — — — — — —

### Task 3 — Search

Noteshelf has no search yet. Add the ability to **search** notes.

Do this in three separate stages, in this order, and **keep each stage on its
own**:

1. **Plan** — work out exactly how search should behave.
2. **Build** — then build it.
3. **Review** — then check that what was built matches the plan.

Ask one of your AI assistants to check the **whole app** — frontend, backend,
and shared code — for anything that doesn't line up.

If it can bring in other assistants to share the work, let it.
