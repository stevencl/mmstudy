# Tests

This folder is intentionally (almost) empty.

Noteshelf ships **without a test suite** — adding one is the first study task.
During the session, participants will use one or more AI chats/agents to write
tests for the frontend, the backend, and the shared layer.

Suggested layout (participants are free to choose their own):

```
tests/
  frontend/
  backend/
  shared/
```

No test runner is pre-configured, so participants can pick whatever they are
comfortable with (e.g. Vitest, Jest, node:test).
